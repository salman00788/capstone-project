# Capstone Project

## Overview

This repository contains my capstone project developed as part of my internship.

## Tech Stack

- Node.js
- JavaScript
- Git & GitHub

## Getting Started

1. Clone this repository.
2. Install [Node.js](https://nodejs.org/) (LTS recommended).
3. Start the local server:

```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view the settings form.

## Features

- Profile settings form (display name, email, bio, theme, notifications)
- Client-side validation with inline field errors
- Saved settings stored in the browser with `localStorage`

## Project Status

A simple settings form with validation is available. Additional features will be added in upcoming tasks.
